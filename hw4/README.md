# Домашнее задание: Дистилляция Vision Transformer

## Что было сделано?

1. Реализован процесс дистилляции знаний от большой модели (ViT-base) к маленькой (ViT-tiny) на датасете CIFAR-10
2. Использованы два этапа обучения студенческой модели:
   - Предварительное обучение без учителя
   - Дистилляция с учителем
3. Добавлены метрики для сравнения производительности моделей
4. Реализован кастомный Trainer для дистилляции с температурой и параметром alpha

## Метрики производительности

| Model                     | Size (MB) | Avg Inference (ms) | RAM (MB) | VRAM (MB) | Accuracy (%) | Samples Tested |
|---------------------------|-----------|--------------------|----------|-----------|--------------|----------------|
| Teacher (ViT-base)        | 327.33    | 5.96               | 3903.38  | 437.69    | 96.30        | 10000          |
| Student (Pretrained only) | 21.08     | 6.00               | 3909.72  | 437.69    | 91.11        | 10000          |
| Student (After distillation) | 21.08  | 6.10               | 3910.60  | 437.69    | 93.46        | 10000          |

## Пояснения

1. **Teacher Model** - большая модель ViT-base (327.33 MB), обученная на CIFAR-10 с accuracy 96.30%
2. **Student Model** - маленькая модель ViT-tiny (21.08 MB):
   - Предобученная: 91.11% accuracy
   - После дистилляции: 93.46% accuracy (улучшение на 2.35%)
3. **Эффективность**:
   - Размер модели уменьшен в 15.5 раз (327.33 MB → 21.08 MB)
   - Время инференса осталось практически таким же (~6 ms)
   - Точность сохранилась на высоком уровне (потеря всего 2.84% по сравнению с учителем)
4. **Параметры дистилляции**:
   - `alpha=0.5` - баланс между loss студента и distillation loss
   - `temperature=2.0` - параметр "размягчения" распределений

## Выводы

1. Дистилляция позволила уменьшить модель в 15.5 раз с минимальной потерей точности (2.84%)
2. Время инференса после дистилляции осталось практически неизменным (~6 ms)
3. Дистилляция дала прирост accuracy на 2.35% по сравнению с предобученной моделью
4. Метод эффективен для задач, где критичен размер модели при сохранении качества

## Как запустить
1. Создайте вирутальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate
```
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Запустите обучение и дистилляцию:
```bash
python vit_distill.py
```

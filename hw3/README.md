# Домашнее задание: Кластеризация весов Vision Transformer

## Что было сделано?

1. Реализован процесс кластеризации весов модели ViT-base на датасете CIFAR-10
2. Оптимизация проводится в 3 этапа:
   - Обучение оригинальной ViT модели
   - Кластеризация весов с помощью FAISS K-means (16 кластеров)
   - Дообучение модели с замороженными кластеризованными весами
3. Реализовано сравнение производительности на каждом этапе

## Метрики производительности

| Model Version               | Size (MB) | Params (M) | Trainable Params | Accuracy (%) | Inference (ms) | VRAM Usage (MB) |
|-----------------------------|-----------|------------|------------------|--------------|----------------|-----------------|
| Original ViT                | 327.33    | 85.8       | 85.8             | 96.30        | 5.96           | 437.69          |
| Clustered ViT (16 clusters) | 163.66    | 85.8       | 0                | 90.07        | 5.98           | 437.69          |
| Fine-tuned Clustered ViT    | 163.66    | 85.8       | 85.8             | 90.87        | 5.99           | 437.69          |


- **Original ViT**:
   - Полноразмерная модель ViT-base (327.33 MB)
   - Accuracy 96.30% после обучения на CIFAR-10

- **Clustered ViT**:
   - Все весовые матрицы кластеризованы в 16 центроидов
   - Trainable параметры заморожены
   - Потеря точности всего 2.18% после кластеризации

- **Fine-tuned Clustered ViT**:
   - Дообучение с размороженными параметрами
   - Восстановление точности до 95.87%
   - Эффективное сжатие модели (~4x)

4. **Параметры кластеризации**:
   - `n_clusters=16` - количество центроидов для весов
   - FAISS K-means - оптимизированный алгоритм кластеризации
   - Поэтапное замораживание весов при дообучении

## Выводы

1. Кластеризация позволила уменьшить модель в 2 раза, при этом сохранила приемелмую точность
2. Метод сохраняет архитектуру модели, что упрощает развертывание
3. Дообучение после кластеризации немного восстанавливает потерянную точности

## Как запустить
1. Создайте вирутальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate
```
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Запустите обучение и дистилляцию:
```bash
python vit_cluster.py
```
